Breakwater is an original tower-defense game: defend the harbor lantern against ten waves of tide-creatures. Place Harpoon, Frost Spire and Cannon towers on the harbor pads, earn gold for every creature sunk, upgrade and sell towers, and hold the light through the final wave — where the Tide King comes. Keyboard and mouse, desktop browser, no network, no libraries; art drawn in code and sound synthesized with WebAudio.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click Start, pick a tower (1/2/3), click a pad to build, and press Space to call the next wave. P pauses, R restarts, M mutes.
